# Archivos y rutas que Claude Code NO debe modificar sin confirmación explícita.
# Una entrada por línea. Soporta globs.
#
# Prefijo '+' = solo-creación: el agente puede crear archivos nuevos ahí, pero no
# modificar los que ya existen. Es lo que necesitan /architect y /contracts, que
# tienen que poder escribir un ADR o un contrato nuevo, mientras que cambiar uno
# ya escrito es una decisión tuya (un ADR no se edita: se reemplaza por otro).
#
# Prefijo '!' = excepción: anula la protección para esa ruta aunque un patrón más
# amplio la cubra. Hace falta porque '.git/**' protege el repositorio entero, y
# /git-setup tiene que poder instalar los hooks en .git/hooks/ — que es justamente
# lo que este workflow existe para hacer. El resto de .git/ sigue intocable.
