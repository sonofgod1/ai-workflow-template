# Archivos y rutas que Claude Code NO debe modificar sin confirmación explícita.
# Una entrada por línea. Soporta globs.
#
# Prefijo '+' = solo-creación: el agente puede crear archivos nuevos ahí, pero no
# modificar los que ya existen. Sirve para documentos que NO se enmiendan nunca:
# un ADR registra una decisión con su fecha y su contexto, y si la decisión cambia
# se escribe otro que lo reemplace. Reescribirlo borraría el registro de por qué
# se decidió lo anterior, que es justamente para lo que existe.
#
# No lo uses para documentos VIVOS. 'docs/contracts/**' estuvo aquí hasta el
# 2026-09-11 y fue un error (hallazgo I2): un contrato de API cambia con cada
# endpoint, así que bajo solo-creación quedaba intocable por cualquier agente
# apenas se escribía la primera vez, y /contracts servía el primer día del
# proyecto y nunca más. La guardia empujaba al peor resultado posible — que el
# contrato quedara mintiendo, porque corregirlo costaba más que dejarlo.
#
# Lo que protege un contrato no es un hook, es la revisión: el plan declara qué
# contratos toca y tú lo apruebas antes de que se escriba nada, y el diff del PR
# muestra el cambio. Eso se lee; un archivo que nadie puede tocar, no.
#
# Prefijo '!' = excepción: anula la protección para esa ruta aunque un patrón más
# amplio la cubra. Hace falta porque '.git/**' protege el repositorio entero, y
# /git-setup tiene que poder instalar los hooks en .git/hooks/ — que es justamente
# lo que este workflow existe para hacer. El resto de .git/ sigue intocable.
